Third-party libraries distributed with SysmonWidget
===================================================

The DLLs in this folder are unmodified .NET Framework builds taken from the
NuGet packages below (https://www.nuget.org/packages/<package>/<version>).
They are loaded by read_temp.ps1 in Windows PowerShell 5.1.

The source code of the MPL-2.0 libraries is available at the repositories and
commits listed. License texts: https://mozilla.org/MPL/2.0/,
https://www.apache.org/licenses/LICENSE-2.0, https://opensource.org/license/mit
